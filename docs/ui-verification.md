# 重启验收清单（v1.1.x 浏览器即时对战 UI）

> 用途：DSH Desktop 重启后逐项核对 v1.1.x 的浏览器面板与对话模式。
> 「代码/运行时已验证」项由自动化（typecheck / verify-engine）覆盖；「需人工」项请在 GUI 中确认。

## 0. 前置：重启与确认版本

1. 完全退出 DSH Desktop，重新打开（client UI 在启动时扫描加载，HMR 对桌面壳不生效）。
2. 确认插件已是新版本：
   - `dsh --profile desktop --dump-config` 应看到 `# == dsh-plugin-feihualing` 层；
   - 若从 npm 安装：`npm view dsh-plugin-feihualing version` → `1.1.1`（`latest`）；
   - 本仓库本地联调（file: 链接）时确保 `pnpm run build` 已执行（`lib/client.js` 存在且为最新）。

## 1. 面板入口（需人工）

- [ ] 进入任意会话，标题行（预设/任务按钮那一排）出现 **🎴** 按钮；
- [ ] 点击 🎴 弹出「飞花令 · 即时对战」浮层（右上角卡片）；
- [ ] 再点 🎴 或点 ✕ 收起；**再打开对局仍在**（若已开局）。

> 若 🎴 不出现：检查浏览器控制台（F12）是否有 client bundle 加载报错；
> 确认 `package.json` 的 `dsh.client` 与 `exports["./client"]` 均存在且 `lib/client.js` 以
> `window.__ModuleLoader__.load({ id: "dsh-plugin-feihualing", ...` 开头（握手格式）。

## 2. 开局与设置（需人工）

- [ ] 模式切换 简易/古法（古法说明文案随之变化）；
- [ ] 难度切换 轻松/标准/困难（下方说明随之变化）；
- [ ] 点「开始对局」：显示大号令字、题号「第 1/7 题」、倒计时（30/20/15s）、对手出句；
- [ ] 对手出的句子必含令字，且「双方用过不能再重复」。

## 3. 对局交互（需人工）

- [ ] 输入含令字的新句回车提交 → 判定通过：得分上涨、题号推进、对手换新句；
- [ ] 连续答对 → 显示连击加成（+10 → +12 → +14…）；
- [ ] 提交重复句/无令字句 → 提示原因、不计分、不换题；
- [ ] 古法模式：令字须位于提示的第 N 字，位置错会被拒；
- [ ] 倒计时走完 → 「超时」计数 +1 并换题；累计 3 次 → 结算惜败；
- [ ] 💡 提示消耗次数并给参考句（直接跟对只 +5 分）；
- [ ] 连对 7 题 → 「通关」结算；结算展示得分/答对/超时与战绩（胜/负/连胜/最佳）；
- [ ] 收起面板（对局中）→ 倒计时暂停；重新打开 → 继续同一题（剩余时间保留）。

## 4. 对话模式回归（需人工）

- [ ] 对模型说「开始飞花令」→ 正常开局（简易/令字/提示次数播报）；
- [ ] 接诗句、要提示、换字、结束游戏均正常（与 v1.0 行为一致——Host 判定已改为
      shared 规则，结果应与 v1.0 相同）。

## 5. 自动化基线（已通过）

```bash
pnpm typecheck   # 0 错误
pnpm test        # ~40 项断言全过（引擎流程 + 规则边界 + 诗库质量审计）
pnpm run build   # lib/index.js + lib/client.js（client 无 react-dom 引用）
```

## 常见问题速查

| 现象 | 处理 |
| --- | --- |
| 🎴 不出现 | 重启后仍无 → 控制台看 client 报错；确认安装的是 ≥1.1.x |
| 面板样式怪（明暗不符/被裁剪） | 记录主题模式与截图，反馈给作者（fixed 定位面板若被宿主容器裁剪需改挂 shell.overlay） |
| 对话模式异常 | 检查 `dsh --profile desktop --dump-config` 中该行 `enable`；Host 异常与面板无关 |
